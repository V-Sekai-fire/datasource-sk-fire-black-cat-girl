# datasource-sk-fire-black-cat-girl

Source files for the black cat fire avatar: the current VRM release, its editable base mesh, and earlier versions and outfits.

## What it is for

`release/` holds the avatar as it ships and the editable base it comes from; `archive/` keeps earlier versions and outfits. The files open in any tool that reads VRM or the avatar editor's `.vroid` format.
